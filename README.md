# 🎂 Happy Birthday Web App

A modern, interactive, and customizable digital birthday celebration web application built with **Next.js 16**, **React 19**, and **Tailwind CSS**.

---

## ✨ Features

- 🕯️ **Interactive Birthday Cake**: Blow out candles with hover, click, or swipe gestures with realistic animated flame flickers and smoke physics.
- 💌 **Notebook Letter with Typewriter Effect**: Beautiful lined notebook paper revealing heart-touching wishes line by line.
- 💐 **Interactive Bouquet & Gifts**: Unbox virtual floral bouquets and animated gifts.
- 🧸 **Clothesline Gallery**: Swaying polaroid photo gallery with wooden clips and lightbox popup dialogs.
- 🎵 **Vinyl Record Music Player**: Aesthetic vinyl music player playing background audio.
- 🎆 **Interactive Fireworks & Falling Petals**: Canvas particle fireworks and falling flower petals.
- 🛠️ **Customizer Studio (`/edit`)**: Full interactive studio with live image crop tools, video/photo uploaders, and instant configuration sharing.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **UI & Animation**: React 19, CSS Modules, Canvas Confetti, Framer Motion
- **Styling**: Tailwind CSS v4, Custom CSS Variables
